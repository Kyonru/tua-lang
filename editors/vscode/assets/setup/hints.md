# Keep the detail you need

**Full** — show complete inferred types and parameter names.

**Compact** — shorten long hints to small ellipses.

**Types Only** — show inferred types, without parameter labels.

**Parameters Only** — label call arguments, without inferred types.

**Off** — hide Tua inlay hints.

You can change this later from the **Tua Tools** menu while editing a Tua file.
Choosing a non-compact mode restores the hint length saved before Compact.
