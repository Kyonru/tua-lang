# Offline LÖVE API Reference

`index.html` is the LÖVE 11.5 single-page API reference from the
`love2d-community/love-api` GitHub Pages branch. It is bundled so the reference
can be opened without an internet connection.

- Upstream page: <https://love2d-community.github.io/love-api/>
- Source repository: <https://github.com/love2d-community/love-api>
- Bundled revision: `40b8704ab12d5109793e7e8f314002dff5a48d15`
- The project describes its content as the LÖVE wiki in a Lua table and notes
  that API information is maintained manually. See the upstream README for
  that project's scope and accuracy note.
- LÖVE's License page identifies the old, imported wiki documentation as being
  under the FreeBSD Documentation License:
  <https://love2d.org/wiki/License>
- Trailing whitespace was removed from the bundled HTML.

The bundled page is provided as a convenience and is not maintained by Tua.
