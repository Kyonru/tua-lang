## Limits and follow-up

- The new class-chain defect is reproducible in CLI/LSP/editor and needs a product fix plus regression test; see [FUP-01](FINDINGS.md).
- The visible suggestion median is materially above warm protocol completion. A timestamped client/renderer trace is required to attribute the gap. The synthetic sample is too small for a release SLA and has no previous-version visible-menu baseline.
- Large graph stress used generated view models. Real compiler graph fidelity, 1,000+ node scaling, and long-term interactions remain unqualified.
- Native asset preview was verified for one PNG; audio/video/font native previews and large assets were not exercised in this follow-up.
- The inspector's default soak command is an unreliable retained-heap oracle unless Node runs with `--expose-gc` or the assertion measures post-GC heap. The forced-GC run passed, but no multi-hour session was tested.
- No Windows/Linux installed host, LuaJIT runtime, prior-version upgrade, or private game project was used. The user did not request a new VSIX in this follow-up, and no product code changed.
