`internal/audits/feature-followup-2026-11-11/starfall-visible-run.js` now
measures the first visible suggestion widget separately from the paint of the
expected candidate labels. In one isolated VS Code 1.142.0 host and the same

Re-run with the scripts above in an installed host. Record trigger, client

## Audio snapshot decision

The built-in top-level `AudioSnapshot` has a stable field set, while ordinary
Lua tables and nested records remain open. Reads and writes of an absent
top-level snapshot field now emit `TL1016`; the reported
`audio:snapshot().musicState` typo fails checking, and
`audio:snapshot().music.state` remains the documented form. Core and LSP
regressions check the direct, saved, indexed, and assignment cases and confirm
ordinary Lua tables stay open. This is intentionally limited to the native
snapshot contract, not a general exact-record feature.

## Pool-to-ECS warning decision

When a directly acquired local is passed to a statically recognized ECS
`world:add`, `TL5007` identifies the receiving component and asks for the
release in component removal or cleanup. It still warns: handoff does not
prove release. A scoped exact-code suppression is appropriate only when the
owner actually releases the object. Regressions confirm a separate forgotten
acquisition still warns and a user-defined `add` method is not treated as ECS.
Aliases, cross-function transfers, and dynamic ownership remain beyond this
lexical warning; the wording makes no claim to prove them.

## Bounded exported type aliases

Decision: a direct exported instance alias of a bounded generic class needs
an alias parameter bound in its public type contract. Present Tua does not
parse `export type JarInstance<T: Named> = Jar<T>`, and the unbounded spelling
`JarInstance<T> = Jar<T>` fails the class bound at declaration. We did not
silently erase the bound or add partial syntax. `docs/classes.md` explains the
checked current pattern (unbounded class instance alias plus bounded exported
factory); `ROADMAP.md` records the parser, checker, imported-type, and editor
acceptance criteria for direct alias-bound syntax.
