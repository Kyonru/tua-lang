## Decision notes

The rendered behavior-tree layout is specific to execution order rather than a generic card grid. Its horizontal scrolling is visible and the root remains in view in the tested narrow case. Avoid redesigning it from a single screenshot. The higher-priority usability issue found here was refresh context loss in four project views (ED-01 in `EDITOR.md`), because it interrupts inspection during edits.

The previous `internal/audits/previews-0.7.0-final/REPORT.md` recorded populated graph, native asset, inspector long-session, and large-graph limits. This run adds small populated Signal/ECS/pool host fixtures and closes the refresh-context and signal-label gaps. It does not establish large-game fidelity. A useful next pass is one representative game that populates all three views from the same compiler snapshot, then verifies every displayed link and warning against source and CLI output. Capture that host run before proposing broader visual changes.
