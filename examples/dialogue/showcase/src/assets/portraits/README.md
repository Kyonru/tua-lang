# Lorelei portraits

Lorelei by Lisa Wischofsky, distributed through DiceBear under CC0 1.0.

- Style and attribution: https://www.dicebear.com/styles/lorelei/
- Original artwork: https://www.figma.com/community/file/1198749693280469639
- License: https://creativecommons.org/publicdomain/zero/1.0/

These transparent 256px PNGs (the API’s returned raster size) were downloaded from DiceBear's 10.x API, using fixed
character seeds and explicit hair/skin settings. Expression variants change only the
eyes, eyebrows and mouth, keeping character identity consistent. `provenance.json`
records every URL, option and file hash. Assets are bundled; gameplay performs no
network requests. The existing slate tile and sage circle are drawn separately by
`portraits.tua` and are not baked into the avatars. Beacon uses a Lorelei radio persona.
