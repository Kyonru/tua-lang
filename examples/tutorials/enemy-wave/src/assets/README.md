# Kenney character artwork

`zombie.png` is the unchanged `PNG/Zombie/zombie_tilesheet.png` from
[Kenney Platformer Characters](https://kenney.nl/assets/platformer-characters),
licensed CC0. The included license and provenance file record its origin and hashes.
The 720×330 atlas contains 80×110 cells; walking uses columns 0 and 6 on row 1.
No network access or image processing is required to run the example.
