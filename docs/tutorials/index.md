# Tutorials

Choose a complete game or a small dialogue introduction. Both start with a playable
result and introduce advanced features gradually.

## Build an arena game

[Follow one evolving game](arena-game/index.md) through movement, pause menus, combat,
enemy decisions, sound, shaders, dialogue, saves and profiling. Every chapter has a
self-contained runnable checkpoint, so you can start at the beginning or inspect one
system in context.

## Your first playable dialogue

[Write a conversation with replies and custom drawing](first-dialogue.md). This short
standalone introduction needs no shooter or arena setup. Continue to the
[dialogue reference](../dialogue.md) when you need richer presentation or advanced flow.

Use [Installation](../installation.md) and [Quickstart](../quickstart.md) to set up
Tua and LÖVE. Feature reference pages cover the full APIs.
