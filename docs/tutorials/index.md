# Tutorials

Start with [Build an arena game](arena-game/index.md): one evolving game with
runnable chapter checkpoints. Its first chapter combines movement, animation,
camera follow and game flow.

The standalone guides below remain available as focused foundations. Each tutorial
has a runnable example and explains which behavior belongs to Tua and which is
chosen by the game. Choose the guide that matches what you want to build.

| I want to… | Start here |
| --- | --- |
| Move and animate a character with a following camera | [Your first playable character](playable-character.md) |
| Add title, pause, resume and restart screens | [A pause menu and game flow](game-flow.md) |
| Keep progress across launches and handle damaged saves | [Save and resume a run](save-and-resume.md) |
| Spawn, damage and reset a small ECS wave | [A wave of enemies](enemy-wave.md) |
| Write a conversation with replies and custom drawing | [Your first playable dialogue](first-dialogue.md) |

Use [Installation](../installation.md) and [Quickstart](../quickstart.md) to set up
Tua. Feature reference pages cover the full APIs; these guides focus on a small
result you can run, understand and change.
