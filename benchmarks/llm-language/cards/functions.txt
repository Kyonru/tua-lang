Function card: annotate parameters after their names and the return type after the parameter list. Keep Lua `function ... end` syntax. Generic free functions use declaration binders such as `local function identity<T>(value: T): T`; direct calls infer `T` without explicit type arguments. Defaults and optional parameters must be trailing. Multiple return types are parenthesized. A function declaring a non-nil result must return that result on every reachable path; recursive calls use the local function name normally.
