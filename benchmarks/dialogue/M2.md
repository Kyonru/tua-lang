# M2: typed dialogue context and locals

Implementation baseline: `c003b5f0` (M1 completion). Feature commit: `ed70c388`;
CLI fixture-isolation commit: `4740ff04`. Both are unsigned. This milestone adds typed,
explicit data updates without changing host rendering, clocks or gameplay state.

## Contract

- `Save.shape(Save.record(...))` captures a headless schema/default snapshot and
  returns typed defaults plus a validating copier. Dialogue accesses captured
  validators through a private weak-key registry, not mutable public callbacks.
- `Dialogue.context({facts, locals})` supplies a concrete typed factory. Direct
  builtin calls retain types through module exports and whole-module re-exports.
- `@context "module"` and `@bind name context.field` / `locals.field` lower to
  schema-two data. Optional paths need compatible scalar defaults. Plain paths
  never execute code; every placeholder in a bound script must have a binding.
- Each player owns facts and locals. `updateContext`/`setLocals` replace complete
  values, refresh text atomically and preserve execution/event identity. `start`
  resets locals, loops keep them, cancel keeps inspection data, disposal releases it.
- Existing context-free assets still emit schema one; legacy documents remain
  playable. Shared scalar formatting preserves localization and literal insertion.
- Editor diagnostics, completion, hover and navigation use the same indexed types.
  Factory-produced record fields now survive module-graph forwarding; navigation
  goes to the factory expression when no separate field declaration exists.

## Evidence

The maintained runtime regression is
`crates/tua-core/tests/fixtures/dialogue-context/lifecycle.lua`. The Rust integration
test also compiles and executes the typed example and authored script, rather than
only testing hand-written Lua. It checks ownership, optional/false values, explicit
refreshes, event replay, restart/loop/cancel/dispose, invalid payloads, arrays,
metatables/cycles, resolver failure, reentrant mutation and descriptor tampering.
Shared-analysis tests cover re-exports, wrong payload types, readonly writes,
completion/hover/navigation, bad paths/defaults, missing placeholders and overlays.
Parser tests reject executable bindings and nonfinite defaults.

The new example runs with standalone Lua 5.4.8. A headless LÖVE 11.5 host also runs
the emitted example and lifecycle oracle under LuaJIT 2.1.1700008891 / Lua 5.1,
with `jit.status()` confirmed false and true in separate runs. No rendered UI or
installed-editor latency claim is made. Standalone Lua 5.1 and LuaJIT executables
were unavailable. Existing M0 compatibility/ownership and M1 localization/lifecycle
oracles pass against rebuilt output. No performance improvement is claimed.

The first repository-wide run stopped when an existing CLI fixture's temporary
source directory disappeared. Its directory name used only process ID and clock;
a monotonic counter now guarantees distinct names within the concurrent test
process. The observed failure was missing test input, not a dialogue diagnostic.
The counter removes timestamp collision as a cause; the original cause was not
independently reproduced.

Final workspace tests pass: 2,122 core tests (one existing ignored), nine core

Clippy passes with warnings denied. Strict docs and explicit Tua/Lua formatting
checks pass. The final `make verify` run passes, including model-contract/reference

## Reproduce

```sh
RUST_MIN_STACK=16777216 cargo test -p tua-core
make verify
make docs-build
(cd examples/dialogue-context && ../../target/debug/tua fmt --check && ../../target/debug/tua check && ../../target/debug/tua build)
(cd examples/dialogue-context/build && lua main.lua)
```

For native checks, copy the emitted build into an isolated directory, rename its
`main.lua` to `run_example.lua`, and copy the lifecycle oracle as `lifecycle.lua`.
Use a headless `conf.lua` (window, graphics and audio disabled) and this host:

```lua
function love.load()
  if os.getenv("TUA_CONTEXT_JIT") == "off" then jit.off() else jit.on() end
  print(_VERSION, jit.version, jit.status(), love.getVersion())
  local ok, message = pcall(function()
    require("run_example")
    require("lifecycle")
  end)
  if not ok then print(message) end
  love.event.quit(ok and 0 or 1)
end
```

Launch once with `TUA_CONTEXT_JIT=off`, once with `TUA_CONTEXT_JIT=on`. Check actual
JIT status on the selected platform instead of assuming enabling it succeeded.

## Remaining general type-system boundary

The shared module-graph change also repairs the original two-argument generic
factory probe: imported update parameters and readonly results now reject the
invalid examples. A follow-up attempt to express this entire API as an ordinary
generic signature with nested `Save.shape(...)` arguments still
inferred `any` in the imported factory and failed the maintained acceptance tests.
M2 therefore keeps concrete compiler-derived context signatures, following the
existing Save pattern. It does not claim to fix all nested generic inference or
permissive unknown-field reads in ordinary imported Tua records. Script field paths
are checked explicitly. Typed events remain M4 work.

The preserved [nested shape factory probe](probes/nested-shape-factory/README.md)
reproduces the remaining boundary without game code. Ordinary explicitly typed
record arguments now retain their types, including the one-options-record variant.
