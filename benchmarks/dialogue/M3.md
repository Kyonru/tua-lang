# M3: conditions, branches and choice availability

Baseline: `0635fdd0` (the separate speech-blip plan addition after M2).
Implementation commit: `b970b18b` (unsigned). M3 keeps
rendering, input, clocks and gameplay actions in the host.

## Implemented contract

- Branch-only labels use `@branch condition [target:yes] [else:no]`.
- Choice metadata uses `@visible`, `@enabled`, a stable-ID `@reason`, and an explicit
  group `@fallback`. Hidden replies are omitted; disabled replies remain visible
  with `enabled = false` and an optional localized reason. No eligible reply follows
  the fallback, rather than accepting a disabled choice or waiting indefinitely.
- Conditions are bounded data instructions: field reads, finite scalars, nil,
  short-circuit boolean operators, scalar equality and numeric ordering. Missing
  optional paths yield nil, boolean contexts treat nil as false, and ordered
  comparisons involving nil return false. Calls/arithmetic/assignment are excluded.
- Shared imported context facts drive diagnostics, completion, hover and navigation.
  Targets are checked at authored spans; reason IDs enter extraction and localization
  coverage. The extension highlights the new directives and condition operators.
- Choice submission rechecks the current accepted facts. Host-table mutation and
  stale UI snapshots do not authorize a reply. Same-node refreshes preserve execution
  identity/events; a no-choice fallback enters a new visit. Failed resolution keeps
  accepted data and presentation intact.
- Conditions cap at 8 KiB authored text, 256 tokens/instructions and 32 AST levels.
  Automatic transitions default to 256 edges per operation, configurable 1–4,096.
  Exceeding the budget yields an inspectable `transition_budget_exceeded` fault.
  Faulted players require explicit start/cancel/dispose; updates do no automatic work.
- Conditional assets emit schema 3. The runtime still accepts legacy/schema 1/2
  documents, and old authored sources retain their previous emitted schema.

## Validation

Maintained fixtures:

- `examples/dialogue-conditions`: typed shop, optional facts, disabled/hidden options,
  explicit fallback, old-choice rejection and fault recovery.
- `crates/tua-core/tests/dialogue_conditions.rs`: parser boundaries plus execution of
  emitted typed source and an authored script under available Lua interpreters.
- `crates/tua-core/tests/fixtures/dialogue-conditions/lifecycle.lua`: short-circuiting,
  nil/false, malformed instructions, nesting/size bounds, deterministic option order,
  ownership between players, current eligibility, failure atomicity, locale refresh,
  local reads and budget/cleanup behavior.
- Shared-analysis tests cover imported/re-exported paths, editor queries, wrong
  operand types and unknown fields. CLI checks cover runtime inclusion, extraction
  of reason keys and invalidation after changing a context field's type.

The complete core suite passes: 2,123 tests (one existing ignored), plus 11 emitted
integration tests. Strict docs and explicit Tua/Lua formatting checks pass. A native
headless host runs the emitted example and lifecycle oracle in LÖVE 11.5 / Lua 5.1 /
LuaJIT 2.1.1700008891, with actual JIT status confirmed false and true in separate runs.
Emitted native runtimes match source byte-for-byte. Standalone Lua is 5.4.8; standalone
LuaJIT/Lua 5.1 binaries were unavailable. No rendered UI or installed-editor claim.

The first broad run failed warm-cache assertions while an explicit compiler rebuild
was replacing the binary. It is not counted as passing. The subsequent full
`make verify` passes with the compiler held stable: workspace tests, Clippy,
model-contract/reference/mutant checks, feature examples, all 292 extension tests,
grammar/theme checks, version/JSON validation and whitespace checks. Final focused
condition tests also pass after the equivalent cursor-bound lint cleanup.

Final compiler: Tua 0.11.0 development build, debug aarch64-apple-darwin, baseline
`0635fdd0` plus the M3 source changes. SHA-256:
`4490573c305e9891b820323601ae2e2682dbcca1f08dc374fa4e0600cbf974db`.
Concurrent unrelated documentation edits were preserved and are not part of M3.
No performance or rendered-FPS improvement is claimed.

## Reproduce

```sh
cargo build -p tua-cli
RUST_MIN_STACK=16777216 cargo test -p tua-core
make verify
make docs-build
(cd examples/dialogue-conditions && ../../target/debug/tua fmt --check && ../../target/debug/tua check && ../../target/debug/tua build)
(cd examples/dialogue-conditions/build && lua main.lua)
```

Do not rebuild the compiler while the cache suite is running. For LÖVE, copy the
emitted example into an isolated directory, rename its main to `run_example.lua`,
and copy the lifecycle oracle as `lifecycle.lua`. Disable window/graphics/audio in
`conf.lua`. Use a host that selects `jit.off()` or `jit.on()`, logs actual runtime/JIT
versions, requires both modules under `pcall`, and exits with a nonzero status on
failure. This is a correctness host, not a rendered showcase or timing workload.

## Follow-ups

shop's purchase line does not itself spend coins. M6/M7 own reveal cues and optional
